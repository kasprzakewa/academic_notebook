Aby uruchomić algorytmy należy mieć zainstalowany kompilator g++11.
Programy napisane są w standardzie c++20.
W każdym z folderów umieszczony jest plik makefile:
- make - kompilacja plików do programów wykonalnych nazwanych tak jak algorytmy
- make clean - czyszczenie zbędnych plików

Sposób uruchamiania:
1) ./algorytm -d plik_z_danymi.gr -ss source.ss -oss output.res
2) ./algorytm -d plik_z_danymi.gr -p2p pairs.p2p -op2p output.res
